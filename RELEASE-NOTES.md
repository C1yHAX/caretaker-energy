# Caretaker Energy 1.0.0

## English

Portable and large diesel/methane generators plus a stationary petrol refinery, with their own unlocks, icons and matching housing colours. Text now follows the game language automatically: English or German, with English fallback for other languages. No manual language setting is needed.

Requires [UE4SS](https://www.nexusmods.com/thelastcaretaker/mods/4) v3.0.1-1125-g527a483b and [AssetBridge](https://www.nexusmods.com/thelastcaretaker/mods/225) 0.4.1, installed separately. Close the game and merge the ZIP's Voyage folder into the installation. Install all eight runtime files, including the new CaretakerEnergyLocalization Lua module. Remove duplicate old CaretakerFuelGenerators/CaretakerPetrolRefinery packages when upgrading. Game target: 0.10.0.653173 / Steam 25982825.

All nine custom string-table entries passed native language-switch tests for en, de, en-US, de-DE and English fallback in a separate empty profile. All non-localization assets retain their previous bytes. This update does not change models, recipes, power or fuel consumption. Full gameplay/save-reload testing of every generator remains outside this language-only check.

## Deutsch

Tragbare und große Diesel-/Methangeneratoren sowie eine stationäre Benzinraffinerie mit eigenen Freischaltungen, Icons und passenden Gehäusefarben. Die Texte folgen jetzt automatisch der Spielsprache: Deutsch oder Englisch, bei anderen Sprachen Englisch als Fallback. Keine manuelle Sprachwahl nötig.

Benötigt [UE4SS](https://www.nexusmods.com/thelastcaretaker/mods/4) v3.0.1-1125-g527a483b und [AssetBridge](https://www.nexusmods.com/thelastcaretaker/mods/225) 0.4.1, separat installieren. Spiel schließen und den Voyage-Ordner aus der ZIP in die Installation kopieren. Alle acht Laufzeitdateien einschließlich des neuen Lua-Moduls CaretakerEnergyLocalization installieren. Doppelte alte CaretakerFuelGenerators-/CaretakerPetrolRefinery-Pakete beim Upgrade entfernen. Ziel: 0.10.0.653173 / Steam 25982825.

Alle neun eigenen Stringtabellen-Texte bestehen die native Sprachwechselprüfung für en, de, en-US, de-DE und englischen Fallback mit separatem leerem Profil. Alle übrigen Assets behalten ihre bisherigen Bytes. Modelle, Rezepte sowie Strom- und Brennstoffverbrauch bleiben gleich. Dies ist keine vollständige erneute Betriebs-/Speicherprüfung aller Generatoren.

Version 1.0.0. Runtime files only / nur benötigte Mod-Dateien.
